# 3 分钟项目演示脚本

## 演示前准备

1. 在项目根目录分别启动：

   ```powershell
   streamlit run app.py
   uvicorn api:app --host 127.0.0.1 --port 8000
   ```

2. 打开 `http://127.0.0.1:8501` 和 `http://127.0.0.1:8000/docs`。
3. 准备一篇允许本地演示的 PDF；关闭桌面通知，不展示真实 API Key。
4. 使用新会话，避免历史数据影响演示。

## 讲解与操作

### 0:00—0:25：介绍目标

讲解：这是一个基于 LangGraph 与 Hybrid RAG 的科研论文助手，覆盖论文发现、PDF 入库、证据问答、长期记忆、人工确认与引用核验。

展示：Streamlit 首页、模型连接正常状态和工作区。

### 0:25—0:55：上传并构建知识库

操作：上传 PDF，点击构建知识库。

讲解：系统用 PyMuPDF 解析正文、表格、图片和页码，按章节进行结构化切分，再建立 FAISS 与 BM25 两套索引。

验收点：页面显示论文数量和生成的检索片段数。

### 0:55—1:35：带来源问答

提问：`论文使用了什么模型和算法？请给出论文名称及页码来源。`

讲解：Supervisor 将问题路由到 RAG，语义召回与关键词召回合并后进行规则重排，Verify 再核对答案中的来源是否出现在本轮证据中。

验收点：显示检索证据、真实文件名、页码和核验状态。

### 1:35—1:55：长期记忆

输入：`我的研究方向是多目标家庭医疗路径规划。`

操作：在长期记忆区查看 `research_focus`，新建会话后询问：`结合我的研究方向，判断这篇论文是否值得作为对比算法。`

讲解：研究偏好按用户隔离并设 TTL；论文正文仍属于会话知识库，不混入长期偏好。

### 1:55—2:25：搜索与人工确认

输入：`搜索论文 multi-depot home healthcare routing`

操作：展示 arXiv 候选结果，选择一项并确认入库。

讲解：下载属于外部副作用，因此先生成 pending action；确认后恢复工作流，且审批是幂等的。

### 2:25—2:45：报告生成

输入：`生成这篇论文的结构化科研报告。`

展示：问题、方法、实验、局限、复现建议和报告下载。

### 2:45—3:00：工程质量收尾

展示：FastAPI Swagger 和测试结果。

讲解：项目提供同步与 SSE 流式 API，并有 41 项自动化测试；ArXiv、OpenAlex搜索与论文下载已封装为MCP Tool，当前边界是规则路由、规则重排和单机 SQLite，README 中已明确说明。

## 失败时的备用说法

- 模型接口暂时失败：展示检索来源，说明系统支持无 LLM 降级，不影响 PDF 解析和检索。
- arXiv 网络不稳定：展示已保存的审批结果，并说明搜索节点的异常会返回确定性错误，而不是卡死工作流。
- 首次 Embedding 较慢：说明首次需要加载本地模型，正式部署会预热并缓存模型。
